# Archit Chhikara · Portfolio

Personal portfolio site. A single static page with no build step and no dependencies apart from Google Fonts.

**Live:** https://archit0700.github.io/

## What's inside
- Live EEG-style trace that doubles as the site navigation
- Internship timeline (IIT Indore → KSAP → University of Southampton)
- Project pipelines with hover-to-explain stages
- "Ask my resume": TF-IDF retrieval over resume chunks, running entirely in the browser
- Light / dark theme, responsive down to phone width, respects reduced-motion

## Run locally
Open `index.html` in a browser. That's it.
